# Island Jiu-Jitsu Washington

Static marketing website for Island Jiu-Jitsu Washington, prepared for GitHub Pages.

## Run locally

From the project directory:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deployment

The home page is in `index.html`. For GitHub Pages, deploy from the repository root on the `main` branch.

## Important content note

The supplied home page links to `programs.html`, `schedule.html`, and `contact.html`. Those pages were not included in the delivered file and should be added before publishing a complete public site.
